# LexFlow - Legal Operations Platform

A comprehensive Legal Case Management Platform with multi-tenant SaaS architecture.

## Tech Stack
- Next.js (App Router)
- TypeScript
- TailwindCSS
- shadcn/ui

## Features
- Multi-tenant architecture (multiple law firms)
- Role-based dashboards (Super Admin, Law Firm Admin, Lawyer, Client)
- Organization management
- Membership system with invitations
- SaaS billing with subscription plans
- Case management
- Document management
- Calendar module
- Task management
- Notification center

## Getting Started

```bash
npm install
npm run dev
```

## Project Structure
- `/app` - Next.js App Router pages
- `/components` - React components
- `/lib` - Utility functions
- `/types` - TypeScript types
- `/data` - Mock data
